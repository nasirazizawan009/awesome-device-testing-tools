# Maintenance

This file is for maintainers.

## Monthly Checks

- Check all links for HTTP errors.
- Remove tools that became unsafe, abandoned, or irrelevant.
- Review open issues and pull requests.
- Keep categories balanced.
- Reject low-value promotional submissions.

## Acceptance Rules

Accept a submission only when:

- The tool is useful for device testing or device-related diagnostics.
- The link works without suspicious redirects.
- The page is safe to open.
- The tool has a clear purpose.
- The description is neutral.
- The item improves the list.

Reject a submission when:

- It exists mainly for affiliate revenue.
- It requires unnecessary software installation.
- It is a duplicate with no extra value.
- It is keyword-stuffed.
- It is unrelated to device testing.
- It asks for placement in exchange for a backlink or payment.

## Main Awesome Index Timing

Do not submit this repo to the main `sindresorhus/awesome` index immediately. Their current guidelines say new lists should be around for at least 30 days before submission and should pass `awesome-lint`.

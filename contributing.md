# Contributing

Thanks for helping improve Awesome Device Testing Tools.

## What Belongs Here

Submissions should be useful for testing or validating physical devices, browser device APIs, or device-related behavior.

Good examples:

- Keyboard testers.
- Mouse and pointer testers.
- Monitor, display, refresh rate, and pixel tests.
- Webcam and camera tests.
- Microphone, speaker, and headphone tests.
- Gamepad and controller tests.
- Browser APIs or developer tools for device input/output.
- High-quality firmware or layout tools directly related to device behavior.

Not accepted:

- Thin affiliate pages.
- Coupon pages.
- Sites with aggressive ads that block the actual tool.
- Malware, forced installers, or unclear downloads.
- Broken links or tools that no longer work.
- Duplicate tools with no clear extra value.
- Pure blog posts unless they are exceptional technical references.

## Submission Format

Add one item to the correct category:

```md
- [Tool Name](https://example.com/) - Short objective description.
```

Rules:

- Description starts with an uppercase letter.
- Description ends with a period.
- Description is objective, not marketing copy.
- Link directly to the useful page, not only to a homepage if a specific test page exists.
- Use HTTPS where available.
- Keep entries alphabetized only when the category already uses that pattern.

## Self-Submissions

Self-submissions are allowed if the tool is genuinely useful.

Disclose it in your pull request:

```text
Disclosure: I maintain this tool.
```

No reciprocal link is required. Do not offer payment, link exchange, or promotional favors for inclusion.

## Optional Badge

If your tool is accepted, you may optionally add a badge to your site or repository:

```md
[![Listed on Awesome Device Testing Tools](https://img.shields.io/badge/listed-Awesome%20Device%20Testing%20Tools-blue)](https://github.com/nasirazizawan009/awesome-device-testing-tools)
```

This is optional and does not affect acceptance.

## Review Checklist

Before submitting, confirm:

- The tool works today.
- The link is not a redirect trap.
- The tool has a clear purpose.
- The page is safe for users.
- The description is neutral and concise.
- The item fits the selected category.
- You checked that the item is not already listed.

## Maintainer Policy

Maintainers may reject, move, edit, or remove entries to keep the list useful. Accepted entries may be removed later if they become broken, abandoned, unsafe, or low quality.
